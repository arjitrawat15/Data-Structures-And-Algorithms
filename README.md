## About This Repository

This repository is my **personal DSA battleground** - a structured, growing archive of competitive programming solutions built from scratch. Every problem here was solved **independently** as part of my journey toward mastering algorithms and cracking top-tier coding interviews.

No copy-paste. No shortcuts. Just logic, sweat, and C++.

## Folder Structure:

```
 Data-Structures-And-Algorithms
 ┣ 📁 Arrays              ─── Sorting, Searching, Prefix Sums, Kadane's, etc.
 ┣ 📁 Graph               ─── BFS, DFS, Dijkstra, Union-Find, Topological Sort
 ┣ 📁 Segment_Trees       ─── Range Queries, Lazy Propagation
 ┣ 📁 SlidingWindow       ─── Fixed & Variable Window Patterns
 ┣ 📁 Trees               ─── Binary Trees, BSTs, LCA, Traversals

```

> More folders actively being added as I explore new topics!
